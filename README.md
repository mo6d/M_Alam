# Al-Masrya — نظام إدارة المخازن

برنامج ويب كامل (يعمل في المتصفح) لإدارة المخازن: أصناف، تصنيفات، مخازن متعددة،
موردين، عملاء، فواتير توريد وبيع، خصم/إضافة تلقائي للمخزون، تحويل بين المخازن،
جرد فعلي، متابعة المديونيات (لنا وعلينا)، تقارير، وسجل عمليات كامل.

## المتطلبات

- Python 3.9 أو أحدث

## التشغيل

### ويندوز
انقر مرتين على `run.bat` (أو شغّله من موجه الأوامر). سيقوم تلقائيًا بإنشاء بيئة
بايثون، تثبيت المتطلبات، ثم فتح البرنامج في المتصفح على:

```
http://127.0.0.1:5000
```

### ماك / لينكس
```bash
./run.sh
```

### تشغيل يدوي (أي نظام)
```bash
pip install -r requirements.txt
python app.py
```

## تسجيل الدخول لأول مرة

- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

**البرنامج هيجبرك تلقائيًا** على تغيير كلمة المرور من أول تسجيل دخول قبل ما تقدر تستخدم أي صفحة تانية — نفس الحاجة بتحصل مع أي مستخدم جديد يضيفه الـ Admin.

## الصلاحيات

- **Admin (مدير)**: تحكم كامل — يشمل المستخدمين، الإعدادات، سجل العمليات،
  النسخ الاحتياطي، إلغاء الفواتير، وحذف الموردين/العملاء/المخازن.
- **Manager (مشرف مخازن)**: يمكنه إضافة مخازن، لكن لا يصل لإعدادات النظام أو المستخدمين.
- **Employee (موظف)**: يمكنه العمل اليومي (فواتير، منتجات، جرد، مديونيات) دون
  صلاحيات إدارية حساسة.
- **Viewer (مشاهدة فقط)**: يمكنه تصفح كل الصفحات والتقارير، لكن لا يقدر يضيف
  أو يعدّل أو يحذف أي بيانات إطلاقًا — مفيد لمراجع حسابات أو مالك يريد المتابعة فقط.

## أهم المزايا

1. **تسجيل دخول إجباري** لكل صفحات البرنامج، مع حماية CSRF على كل النماذج.
2. **المنتجات**: اسم، كود (SKU)، باركود، تصنيف، وحدة، سعر بيع، سعر تكلفة،
   حد أدنى للمخزون، وصورة اختيارية للمنتج.
3. **مخازن متعددة**: كل صنف له رصيد مستقل في كل مخزن.
4. **فواتير التوريد (الواردات)**: عند الحفظ تتم **زيادة** المخزون تلقائيًا،
   مع دعم نسبة خصم ونسبة ضريبة على مستوى الفاتورة، وإمكانية تسجيل دفعة
   (سداد) للمورد فورًا أو لاحقًا.
5. **فواتير البيع (الصادرات)**: عند الحفظ يتم **خصم** الكمية المباعة تلقائيًا
   من المخزون المُدخل مسبقًا، مع منع البيع بكمية أكبر من المتاح، ودعم نسبة
   خصم ونسبة ضريبة، وإمكانية تسجيل مبلغ محصّل من العميل فورًا أو لاحقًا.
   كمان فيه دعم قارئ الباركود (USB) لإضافة الصنف تلقائيًا للفاتورة.
6. **المديونيات (صفحة "المديونيات لنا وعلينا")**:
   - كم مستحق لنا على كل عميل لم يسدد بالكامل (وكم دفع فعلًا).
   - كم مستحق علينا لكل مورد لم نسدد له بالكامل (وكم دفعنا فعلًا).
   - يمكن تسجيل دفعة/سداد جديد من صفحة كل فاتورة مباشرة.
7. **الجرد**: اختيار مخزن، إدخال الكمية الفعلية المعدودة لكل صنف، والفرق بين
   الرصيد بالنظام والكمية الفعلية يتم حسابه وتسويته في المخزون تلقائيًا،
   مع الاحتفاظ بسجل كامل لكل عملية جرد.
8. **البحث الشامل**: مربع بحث في الشريط الجانبي يبحث في نفس الوقت عن
   المنتجات، العملاء، والموردين.
9. **تحويل بين المخازن** و**تسوية يدوية** لأي رصيد.
10. **تقارير**: قيمة المخزون، الأصناف الأكثر مبيعًا، أفضل العملاء والموردين،
    وتصدير تقرير المخزون بصيغة CSV.
11. **سجل حركة المخزون** الكامل (وارد/صادر/تحويل/تسوية) لكل صنف ومخزن.
12. **سجل العمليات (Audit Log)** لكل الإجراءات المهمة، ونسخة احتياطية لقاعدة
    البيانات بضغطة زر (Admin فقط).
13. **إلغاء الفاتورة (Void)**: أي فاتورة بيع أو توريد ممكن تتلغي بواسطة Admin
    مع سبب الإلغاء، والمخزون يترجع تلقائيًا لوضعه قبل الفاتورة. لو الكمية
    اتباعت أو اتحوّلت بالفعل، البرنامج يمنع الإلغاء ويقولك السبب.
14. **طباعة الفاتورة** بتصميم منظم (زرار طباعة في صفحة عرض أي فاتورة).
15. **تغيير كلمة المرور الذاتي**: أي مستخدم يقدر يغيّر كلمة مروره، والبرنامج
    يجبر أي مستخدم جديد (بما فيهم admin الافتراضي) على تغييرها أول مرة يدخل.
16. **تنبيه فوري بالحد الأدنى**: شارة حمراء في الشريط الجانبي بعدد الأصناف
    اللي وصلت أو تحت الحد الأدنى، محدثة لحظيًا.
17. **حماية من الأخطاء**: أي قيمة غير رقمية تُدخل بالغلط بترجع رسالة عربي
    واضحة بدل ما الصفحة توقف، وأرقام الفواتير محمية من التكرار حتى لو
    اتحفظ فاتورتين في نفس اللحظة بالظبط.
18. **صفحة تفاصيل مجمّعة لكل عميل/مورد**: تدوس على "التفاصيل" جنب أي عميل أو
    مورد فتشوف كل فواتيره، إجمالي تعامله، وإجمالي المتبقي له/عليه في مكان واحد.
19. **نسخ احتياطي تلقائي يومي**: البرنامج ياخد نسخة احتياطية تلقائية مرة واحدة
    يوميًا عند أول تشغيل، ويحتفظ بآخر 30 يوم فقط (بيتحذف القديم تلقائيًا).
    كل النسخ متاحة للتنزيل من صفحة "النسخ الاحتياطية".
20. **صلاحية Viewer (مشاهدة فقط)**: دور جديد يقدر يشوف كل حاجة في البرنامج
    بس ممنوع من إضافة أو تعديل أو حذف أي بيانات — الحماية مطبقة على مستوى
    السيرفر نفسه، مش بس إخفاء الأزرار من الواجهة.
21. **رسم بياني للمبيعات**: جراف بسيط في الداشبورد يوري مبيعات آخر 14 يوم.
22. **خصم وضريبة على مستوى الفاتورة**: كل فاتورة (بيع أو توريد) تقدر تحدد
    لها نسبة خصم ونسبة ضريبة، والإجمالي بيتحسب تلقائيًا (الفرعي → بعد
    الخصم → بعد الضريبة)، وكل ده معروض في صفحة عرض الفاتورة.
23. **Pagination**: قوائم المنتجات (50 لكل صفحة) وسجل الحركات (100 لكل صفحة)
    بقت مقسّمة صفحات، عشان تفضل سريعة حتى لو الداتا كبرت جدًا.

## قاعدة البيانات

ملف SQLite واحد باسم `almasrya.db` يتم إنشاؤه تلقائيًا بجانب `app.py` عند أول
تشغيل. يمكن أخذ نسخة احتياطية منه من صفحة "نسخة احتياطية" داخل البرنامج،
أو بنسخ الملف يدويًا.

## ملاحظة أمنية

هذا البرنامج مصمم للعمل على جهاز واحد أو شبكة داخلية موثوقة (المخزن/المكتب).
لا تعرّض المنفذ 5000 للإنترنت مباشرة دون طبقة حماية إضافية (مثل VPN أو
reverse proxy مع HTTPS).


## التحديثات المحاسبية الأخيرة

- **تقرير الربح والخسارة المحسّن:** يحسب المبيعات، تكلفة المبيعات، الربح الإجمالي، المصاريف، الدخل الإضافي، صافي الربح وصافي الخسارة تلقائياً، مع فلترة حسب الفترة.
- **تثبيت تكلفة البيع:** يتم حفظ سعر التكلفة داخل بند البيع وقت إنشاء الفاتورة، حتى لا تتغير أرباح الفواتير القديمة عند تعديل سعر تكلفة المنتج لاحقاً. وتتم تهيئة البيانات القديمة تلقائياً عند أول تشغيل.
- **تصنيف حركات الخزانة:** يمكن تحديد ما إذا كانت الحركة تؤثر على الربح والخسارة. استخدم ذلك للحركات التشغيلية، وألغِ الخيار للسحب الشخصي أو التحويلات أو القروض ورأس المال.
- **المرتجعات الجزئية:** يمكن تسجيل مرتجع بيع أو توريد من صفحة الفاتورة، مع منع تجاوز الكمية المتبقية، وتحديث المخزون والمديونيات وتقارير الربح والخسارة تلقائياً.
- **تنبيهات الدقة:** يعرض النظام تنبيهاً عند وجود صنف مباع بلا سعر تكلفة أو بسعر تكلفة يساوي صفراً.

> يفضّل أخذ نسخة احتياطية من ملف `almasrya.db` قبل أول تشغيل للنسخة المحدثة، رغم أن الترحيلات الجديدة مصممة للحفاظ على البيانات الحالية.


## التحسينات المحاسبية المكتملة لاحقاً

يتم الآن تحديث سعر تكلفة المنتج باستخدام **متوسط التكلفة المرجح المتحرك** عند تسجيل توريد جديد، اعتماداً على كمية المخزون الحالية وتكلفتها مع كمية التوريد وسعرها. وتظل تكلفة كل فاتورة بيع مثبتة داخل بند البيع وقت إنشائها.

يعرض تقرير الربح والخسارة **مقارنة تلقائية بالفترة السابقة المماثلة** عند تحديد تاريخ البداية والنهاية، مع صافي الفترة السابقة وقيمة التغير ونسبته.

يمكن للمدير من صفحة الإعدادات تحديد **تاريخ إغلاق الفترة المالية**. عند وجود تاريخ إغلاق، يمنع النظام تسجيل فواتير أو دفعات أو حركات خزانة أو مرتجعات بتاريخ يساوي تاريخ الإغلاق أو أقدم منه. لمسح القفل، اترك الحقل فارغاً ثم احفظ الإعدادات.


## مراجعة قسم الحسابات وتصحيحات عامة

أصبحت صفحة **الحسابات** لوحة مالية عملية تعرض الرصيد النقدي المسجل، تحصيلات العملاء، سداد الموردين، الذمم المدينة والدائنة، قيمة المخزون، وصافي المركز التشغيلي، بالإضافة إلى آخر النشاطات المالية. كما أصبحت إجماليات العميل والمورد وتفاصيل الفواتير تعتمد على صافي القيمة بعد المرتجعات.

تم أيضاً توحيد مؤشرات لوحة التحكم مع المرتجعات، فأصبحت مبيعات اليوم والشهر ومنحنى آخر أربعة عشر يوماً وصافي التوريد الشهري تعرض القيم الصافية عند وجود مرتجعات.


## تحديثات المرتجعات والواجهة

عند تسجيل مرتجع بيع يمكن اختيار **خصم القيمة من رصيد العميل** أو **ردها نقداً** أو **ردها بتحويل بنكي**. في حال الرد النقدي أو التحويل، تُسجل الحركة تلقائياً كخروج من الخزانة مع تأثير محاسبي صفري على الربح والخسارة، لأن الرد ليس مصروفاً تشغيلياً.

أضيفت إلى صفحة النسخ الاحتياطية إمكانية رفع ملف قاعدة بيانات صالح واستعادته بعد فحص سلامة SQLite، مع حفظ نسخة أمان تلقائية من قاعدة البيانات الحالية قبل الاستبدال.

تم تحديث الهوية البصرية للتطبيق بالكامل بألوان زرقاء داكنة وسماوية، شريط جانبي مقسم حسب الوظيفة، رابط نشط للصفحة الحالية، تخطيط متجاوب للهاتف، وقائمة جانبية قابلة للفتح على الشاشات الصغيرة. كما أعيد تصميم واجهة تسجيل الدخول بتخطيط تعريفي حديث وحقول أوضح.


## تعديل الفواتير والتقارير المتقدمة

أضيفت إمكانية تعديل فواتير البيع والتوريد من شاشة عرض الفاتورة أو من قائمة الفواتير. يشمل التعديل الطرف، المخزن، التاريخ، الملاحظات، الخصم، الضريبة، الأصناف، الكميات والأسعار. يعيد النظام حساب الإجمالي، ويعيد مزامنة المخزون، ويُبقي الدفعات والمرتجعات وسجل العمليات مرتبطاً بالفاتورة.

لا يمكن تعديل فاتورة ملغاة أو فاتورة داخل فترة مالية مغلقة. كما يمنع النظام جعل إجمالي الفاتورة أقل من المدفوع أو المرتجعات المسجلة، ويمنع حذف بند له مرتجع أو تغيير سعره بعد تسجيل المرتجع حتى لا تتغير القيمة التاريخية. وتحتاج المبيعات بأقل من التكلفة إلى صلاحية المدير.

أضيف إلى مركز التقارير تقرير مستقل للتدفق النقدي، وتقسيم أعمار الديون، وتقرير الأصناف الراكدة وبطيئة الحركة، وتنبيه المبيعات بأقل من التكلفة. كما أضيف تصدير CSV لهذه التقارير بالإضافة إلى تقرير المخزون الحالي.


## إصلاح تسوية المخزون وعداد التنبيهات

تم إصلاح شاشة تسوية المخزون بحيث لا يمكن إنشاء رصيد لصنف لا يملك صفاً موجوداً في المخزن المحدد. يجب تسجيل توريد أو تحويل للصنف أولاً، ثم يمكن تعديل الكمية بالتسوية. كما تم منع الكميات السالبة.

تم أيضاً دمج صفوف المخزون المكررة القديمة لنفس الصنف والمخزن عند تشغيل البرنامج، وأصبحت عملية التسوية تحدّث الصف الموجود بدلاً من إنشاء صف إضافي. وجرى تصحيح عداد التنبيهات في الرئيسية ليحسب الأصناف التي لها حد أدنى فعلي فقط، لا عدد عمليات التسوية أو الصفوف غير الصحيحة.
